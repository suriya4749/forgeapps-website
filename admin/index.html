How to get a token
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → forgeapps-website.
  3. Permissions → Repository → Contents: Read and write.
  4. Generate, copy and paste it here. It only works for this one repo.
